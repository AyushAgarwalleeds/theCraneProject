USB setup

Install one ESP32-WROOM receiver and up to four handheld senders. The wizard saves their pairing on the boards.

Use a USB data cable and desktop Chrome or Edge. Keep the relay contacts disconnected from the crane.

    Receiver

    This setup replaces the receiver’s saved sender list.

    USB diagnostics

    Connect one board to see its Wi-Fi or ESP-NOW status. Power both boards during a radio check.

    Setup details

    Keep the Wi-Fi password and downloaded report private.

    USB troubleshooting
    • Close Arduino Serial Monitor and any other app using the COM port.
    • If the board cannot enter upload mode, hold BOOT, tap EN, then release BOOT and retry.
    • Use a classic ESP32-WROOM development board with at least 4 MB flash. ESP32-S3, C3 and other chips require different firmware.
    • Keep this tab open until setup finishes. If an upload succeeded but pairing failed, connect the same board and choose Retry pairing only.
